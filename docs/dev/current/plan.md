## 1. 剩余工作：聚合判定校准

判定批次仍有四项聚合判据越界，成因见 [`status.md`](../status.md) §5。四项都不能靠现有效用系数解决：

- 近筐份额：需要让突破在 5–14 英尺稳定产生抛投，属于出手种类生成的结构改动；
- 空切份额：需要把空切接进目标生成，而不是调基础分；
- 回合数：节奏由动作时长与决策间隔决定，不在效用权重上；
- 使用率层级：需要按原型改写名册的 `shoot_frequency`，名册不在上一轮改动范围之内。

按 `docs/protocol.md` §1 第 7 条，校准必须单独成一次改动，不与机制改动混在一起。

## 2. 依赖关系

四项互相独立，可以并行；近筐份额与空切份额都需要先定下出手种类与跑位目标的生成规则，使用率层级只动名册数据。
