## 0. 为什么需要这份方案：落地失败的根因分析

北极星（O1 真实）稳定、设计文档完整，但**实际产出与北极星的距离没有随工作量收缩**。2026-09-11 实测基线（命令见 §7.1）：

| 量 | 实测 | 真实带 | 差距 |
| --- | --- | --- | --- |
| 3P 命中率中位数 | **65.8%** | 30–40% | +26pp |
| 场均回合数 | **258.6** | ~200 | +29% |
| 场均 2P 出手 | **~10 次**（2P=10/15） | ~55 次 | -82% |
| 失误率 | **~0.50** | ≤0.35 | +15pp |
| 回合无归因结束（`UNATTRIBUTED_END`） | 91 / 6,779 | 0 | 账本破缺 |
| realism index 均值 | 0.994 | — | 高分假安全感（§0.2） |

从第一性原理看，落地失败不是"工程量不够"，而是**三个结构性错误**反复出现：

### 0.1 结构性错误一：里程碑被"形式达成"掏空

M1–M10 在 docs/dev/cycles/20260901_historical/status_snapshot.md §24 全部记为"~100%"，但同一文档的 §7 与本周期旧状态章节 §26–§29、problem.md §13 证明：3P% 门、回合零遗漏、事件 ID、回合账本、World 私有化、战术 slot fill **从未通过其各自声明的验收标准**。"全里程碑绿"与"验收门未过"在同一份文档里长期共存。

**第一性原理**：验收只能是**验收标准本身**的逐条满足，不能是"做了相关工作"。凡不能以一条可机械执行的命令判红/绿的验收项，等价于没有验收。

**对策**：本方案所有阶段（D0–D6）以**门（gate）**结账，每门附命令与通过条件；阶段完成 = 门全绿，不接受"基本完成"。

### 0.2 结构性错误二：评判器给出高分假安全感

realism index 均值 0.994，而 3P% 是真实值的 1.6 倍、2P 出手几乎消失。直接原因在 quality.md 设计内部：逐回合准则（节奏、走廊、归因）覆盖了"回合内部像不像"，但**没有任何准则覆盖"一场比赛的动作构成像不像"**——出手区域构成（2P/3P/FT 配比）、全队失误率这类**比赛级构成量**落在评判盲区，只被 sanity net 粗筛，而 sanity net 按宪章 C2 不是真实度裁决。

**第一性原理**：参考系是分布不是单点（charter §6）——分布必须覆盖**构成**，不只是条件量。一个每场投 100 个三分、10 个两分的引擎，无论逐回合多合法，都不是篮球。

**对策**：D2 阶段为评判器补**比赛级构成准则簇**（§3.2），且按 gap.md §15.1 引入 `NotApplicable`/`InsufficientEvidence` 证据模型与固定分母，堵住"没证据=满分"。

**但修正一个更深的错误**——"统计分布进带 = 真实"这个命题本身不成立：

1. **古德哈特定律**：指标一旦成为目标，就会被优化到失去信息量。纯曲线拟合可以在每个注册分布上进带，而过程依然错误——把三分基线调低、三分效用调低可以让 3P% 与构成双双进带，但如果代价是球员在快攻大空位也不敢出手（决策模型残废），这只是把失真从统计层赶到了行为层；
2. **充分统计量不存在**：任何有限准则集都是真实比赛分布的低维投影。可以被投影区分 = 能被抓到的失真；无法被投影区分 = 藏进暗角的失真。准则簇只能不断扩大覆盖，永远不等于全集；
3. **逐带独立通过 ≠ 联合分布真实**：出手构成、失误率、节奏、命中率各自在带内，它们的**相关性结构**仍可能错误——真实比赛中 pace 与失误率负相关、领先方末节压节奏、犯规多的比赛罚球占比上升。逐带通过对此失明；
4. **分布进带在逻辑上只是"不荒谬"**：它保证的是"可能但不像"中最粗糙的一层被排除，不保证"像"。

因此正确的因果方向必须反过来（charter §5 本来就是这么立的，落地时走反了）：**统计进带是果，不是因；行为的因果机制真实（能力→决策→执行→结果）是因，分布只是机制正确的可观察投影**。分布对不上的正确机制可能存在（标定未到），机制错误的分布对上也存在（曲线拟合）——两者都说明分布匹配既不充分也不必要，**必要且充分的是机制的正确性**，但机制不可直接验收，所以只能回到宪章的结构：用 O2（无硬编码/纯函数）保证机制的形式合法，用扰动测试保证机制确实在消费能力输入，用分布准则做逼近信号与回归网，用盲区登记制度承认覆盖永远不完备。

**对策（落在 D2/D3）**：构成准则只是**必要条件的回归网**（进带不庆祝，出带必报警）；与之并行的机制守卫是能力扰动测试（quality.md §6）与"无剧本"红线（C1）；D2 必须同时交付**评判盲区登记清单**（§5.5），显式承认当前准则集之外的可观察量；D3 的每个校准 PR 除分布对比外，必须附**机制层证据**（扰动测试不退化 + 缺陷账本定向收缩），防止纯曲线拟合蒙混过门。

### 0.3 结构性错误三：工程产能耗散在展示面，核心因果链长期破缺

git log 显示近期大量提交在 UI（战术路线绘制、运球动画、2K 风格卡片），而 problem.md 记录的 F4（事件 ID、账本、World 私有化）、F5（slot fill、防守执行链）等核心缺口数月未动。同时 §27→§29 连续出现"声称完成→被证据推翻"的活锁修复与账目错误。

**第一性原理**：优先级必须是 `状态与因果正确性 > 物理与规则合法性 > 可解释行为差异 > 真实分布拟合 > 性能与存储 > 展示与便利`（gap.md §1.2）。在账本破缺（`UNATTRIBUTED_END > 0`）的系统上做任何展示面，都是在放大错误。

**对策**：本方案冻结展示面工作（§6.4 非目标），阶段顺序严格执行因果 → 评判 → 校准 → 结构 → 战术。

## 1. 第一性原理推导：这场比赛模拟到底是什么

从最小不可约的事实出发：

**P1 · 一场比赛的唯一真相是一条满足守恒律的事件序列。**
比分、球权、时间、犯规都是这条序列的**派生计数**。任何派生量与事件序列不一致 = 系统说谎。守恒式（gap.md §7.5）：

- 得分守恒：每场总分 = Σ 得分事件载荷；
- 球权守恒：回合数 = 跳球 + 得分后换发 + 篮板易主 + 失误 + 节末，每次球权转移有且只有一个因果事件；
- 时间守恒：Σ 回合时长 + 死球时长 = 比赛时钟消耗；
- 犯规守恒：个人犯规数 = Σ 犯规事件，bonus 状态由计数派生。

→ **推论**：账本（ledger）不是锦上添花，是"系统是否在说真话"的判定器。`UNATTRIBUTED_END > 0` 的引擎不具备被校准的资格，因为校准的输入证据本身是破的。这就是 D0 排第一的原因。

**P2 · 行为只能是 (能力, 规则, 状态) 的纯函数，统计形态只能是校准的果。**
当前的统计失真有确切机制（§4.1 根因分解），不是玄学：出手效用函数让三分在几乎一切局势下占优，于是构成失真；命中模型把三分基线叠加到 65%，于是命中率失真。两者都是**参数层面的错误**，都可以通过 GameRules/DecisionRules 通道修正——这正是 charter C1 + 校准协议存在的理由。

→ **推论**：校准不是"调参调到像"，而是**用评判器的缺陷账本选题、用构成准则定方向、用扰动测试防退化**的闭环。没有构成准则（D2）之前，禁止开始校准（D3）——用盲人校准会放大错误（fix_plan.md 的关键纪律，已被验证正确）。

**P3 · 评判器的可信度必须先于被评判对象，且评判永远不完备。**
当前评判器 0.994 的均值与肉眼可见的失真并存，说明评判器本身有构成盲区。宪章 C2 要求"评判落地到每个回合每个阶段"，其隐含前提是**评判覆盖被显式声明、盲区被显式登记**：凡是未被任何准则覆盖的可观察量，都是真实性可以藏身的暗角——而暗角不可能被消灭，只能被记录在案并逐轮压缩。

→ **推论**：D2（评判器补全 + 盲区登记）在 D3（校准）之前；D2 的验收本身用合成流负面对照（构造已知失真的流，评判器必须报缺陷）。

**P4 · 验收是三层结构，分布匹配只是其中一层。**
单场"看起来像"不可复现、不可比较；纯分布匹配可被曲线拟合欺骗（§0.2 修正）。合法的验收形态必须三层同时成立：

1. **机制层**：行为是 (能力, 规则, 状态) 的纯函数（C1 红线 + 内联常数守卫），能力扰动测试全绿（每个能力维度有可观测的单调行为响应链，quality.md §6）——保证"统计形态来自机制而非脚本"；
2. **分布层**：N 场（≥8）模拟产出在每个注册准则（含构成准则）上落入参考带，且 top 缺陷准则跨两轮单调收缩（charter §8.2）——保证"机制的输出在可观测投影上逼近真实"；
3. **反事实层**：针对性场景测试（快攻、错位、节末压哨、bonus 边界、大比分领先/落后）中行为定性正确——直接防御古德哈特，因为这些场景的决策合理性无法靠全局分布拟合伪造。

三层中任何一层失败 = 不验收。分布层单独通过**不构成**成功，只构成"未被抓到"。

## 2. 总目标与阶段划分

### 2.1 本周期总目标

把引擎从"**L1 零违反但统计失真、账本破缺、评判失明**"推进到"**因果账本闭合 + 评判覆盖构成 + 统计形态进入真实带 + 结构契约补齐**"，具体即 §8 的六组门全绿。

### 2.2 阶段依赖图

```
D0 因果账本会合 ──► D1 证据模型 ──► D2 构成准则簇 ──► D3 统计形态校准 ──► D4 结构契约 ──► D5 战术与防守 ──► D6 全矩阵验收
     │                                       ▲
     └──────── 每个阶段结束：黄金哈希按协议重冻结 + status.md 留证据 ──┘
```

依赖论证：

- **D1 依赖 D0**：证据模型（NotApplicable/固定分母）以账本闭合为前提——账本破缺时"证据不足"与"真通过"无法区分；
- **D2 依赖 D1**：新准则必须直接生在正确的证据模型上，避免二次迁移；
- **D3 依赖 D2**：校准的选题与验收都来自构成准则，fix_plan.md 已确立"评判器错时校准会放大错误"；
- **D4 不依赖 D3，但排在 D3 后**：D3 是行为层修复，D4 是结构重构（World 私有化、事件 ID），行为层先收敛可让 D4 的黄金哈希重冻结次数最少（重构 = 行为中性，一次冻结）；
- **D5 依赖 D4**：slot fill 与防守执行链以事件 ID/动作生命周期为观测基础；
- **D6 是终验，不实现新功能**。

### 2.3 每阶段通用纪律（不再逐条重复）

1. **先红后绿**：每个修复先写失败测试（含负面对照），再实现；
2. **协议证据**：任何默认值改动走 protocol.md §1 校准协议（基线快照 → JSON override → ≥8 seed 对比 → 归因 diff → 黄金哈希重冻结 + 一行说明）；
3. **资源纪律**：遵循 problem.md §14.4——默认 `cargo check -p <crate>`，长测试用 `./scripts/run-tests.sh`，事件流写 `/dev/shm` 逐 seed 清理，构建前后记录 `df -h` 与 `du -sh target`；
4. **逐条结账**：阶段完成与否按 todo 条目标号逐条对照本方案的门，禁止合并、禁止凭印象（本周期旧状态章节 §29.3 教训）；
5. **证据落盘**：每阶段结束把命令、输出、门状态写入 status.md 新一节，并更新本文档 §8。

## 3. D0 · 因果账本会合（优先级最高）

> 目标：每一场比赛的时间、球权、得分、犯规四本账全部可从事件流独立重建且平衡；`UNATTRIBUTED_END` 归零。

### 3.1 现状（可复现）

- problem.md §13.2：seed=0..99 共 6,779 个 `PossessionSummary`，`UNATTRIBUTED_END` = 91，分布于 62/100 场；
- problem.md §13.2 违例回合 `turnover_player_id` 仍有缺失；
- gap.md §7.3/§7.5：`PossessionLedgerEntry` 与四个平衡式不存在（`grep -rn Ledger crates` 仅命中日志字符串）。

### 3.2 工作项

**D0.1 回合终结归因穷举**

- 在 `engine` 的 `emit_possession_summary` 路径上，把"回合结束"改为必须携带 `PossessionEndCause` 显式枚举（SCORE / DEFENSIVE_REBOUND / TURNOVER_STEAL / TURNOVER_PASS_TIPPED / TURNOVER_PASS_DROPPED / VIOLATION / PERIOD_END），**移除 `UNATTRIBUTED_END` 兜底**——编译期强制（枚举无该变体），而非运行时祈祷；
- 每个终结原因必须同时填充责任字段（`turnover_player_id`/`rebounder_id`/`shooter_id`），缺失即编译错误或断言失败；
- 红测试：构造当前能触发 `UNATTRIBUTED_END` 的种子（problem.md §13 矩阵中 62 场），修复后断言全矩阵为 0。

**D0.2 四式账本平衡检查器（invariants 或 evaluator 侧离线工具）**

- 得分守恒：终场比分 = Σ 得分事件载荷（含 FT 逐次 +1）；
- 球权守恒：possession 序列满足"每次转移恰有一个因果事件"且队伍交替合法；
- 时间守恒：Σ summary.duration + Σ 死球区间 = 时钟消耗（容差一个 tick）；
- 犯规守恒：`frame.fouls` 计数 = Σ 犯规事件。
- 产出 `ledger_violations.ndjson`；任何一式不平衡 = Hard。

**D0.3 回合时长真值化**

- `duration_seconds` 改由单调 `current_time` 差值派生，**删除 `.max(0.1)` 填充**（problem.md §2 P1 明确禁止）；真实亚秒回合允许存在，但必须由实际 tick 数支撑。

## 4. D1 · 证据模型与构成评判基础

> 目标：评判器不再给"高分假安全感"——每个准则有固定分母，证据不足显式标注，Hard 缺陷使指数失效而非仅降分。

### 4.1 工作项

**D1.1 Judgment 三态化（gap.md §15.1）**

- `Judgment` 增加 `NotApplicable` 与 `InsufficientEvidence` 变体；
- 每条准则输出 `{opportunities, passes, defects, not_applicable, insufficient}` 固定分母五元组；
- 空流/窗口内无证据的准则输出 `InsufficientEvidence`，**不得计入 pass**（当前空证据按 pass 计是 0.994 的来源之一）。

**D1.2 Hard 门与指数解耦（gap.md §15.3）**

- `AttributionReport` 增加 `hard_gate_failed: bool`；存在任一 Hard defect 时 `realism_index` 标记 `invalid` 而不是输出一个仍接近 1 的数；
- 报告必须同时列出：各准则缺陷率、证据覆盖率（passes+defects / opportunities）、insufficient 占比。

**D1.3 严格解析默认化（gap.md §15.4）**

- `parse_stream` 默认严格（坏行 = 错误退出），软解析仅在显式 `--lenient` 下可用；
- 评判器对 facts 模式的 `stream_projection` 正确区分"未采集"与"损坏"（沿用 v1.41 口径，补测试）。

### 4.2 验收门

| 门 | 命令 | 通过条件 |
| --- | --- | --- |
| G-D1a | evaluator 单测（含合成流负面对照：空流、截断流、无源得分流） | 空流不得满分；无源得分流必须 Hard defect |
| G-D1b | seed=0..7 `1q` 评判 | 报告含五元组分母与 `hard_gate_failed` 字段；存在 Hard 时指数 invalid |
| G-D1c | `./scripts/run-tests.sh` | 全绿 |

## 5. D2 · 比赛级构成准则簇 + 评判盲区登记（本方案新增，修补 §0.2 盲区）

> 目标：评判覆盖"一场比赛的动作构成"，让 3P% 65%、2P 出手 10 次这类失真**必然**被评判器捕获为缺陷，而不是只被 sanity net 粗筛。
> 定位限定：构成准则是**必要条件的回归网**——进带不庆祝，出带必报警；它不证明真实，只证明"未被抓到"（§0.2 修正、§1 P4）。

## 6. D3 · 统计形态校准（本周期核心交付）

> 目标：通过 GameRules/DecisionRules/ResolveConfig 通道校准，使构成量进入参考带。这是"落地效果差"的直接修复。
> 防退化限定：按 §0.2 修正，分布进带可被纯曲线拟合伪造。本阶段每个校准 PR 的证据是**双层的**——分布层（进带）+ 机制层（扰动测试不退化、场景测试定性正确、无新增内联常数）。缺机制层证据的校准 PR = 裸调，打回。

### 6.1 根因分解（已定位，非猜测）

当前失真的机制链（问题不在于"参数没调好"，在于**效用结构系统性地偏向三分**）：

1. **三分效用占优**：`three_point_utility_multiplier = 0.68`（rules.rs:190）与出手效用中三分项的期望收益（0.658 × 3 ≈ 1.97 分/次）远超两分（~0.5 × 2 = 1.0 分/次）——**理性球员在给定命中模型下必然全场投三分**。构成失真（3PA 率 ~0.85、2P 出手 10 次）是命中模型失真的下游结果；
2. **命中模型叠加过高**：`shot_make_3pt` 基线 + `spacing_bonus` 直接加在命中率上 + `shot_pct_ceiling = 0.85` 几乎不构成上界约束（历史 fix_plan §F3.1 已指明该叠加）；
3. **失误率 ~0.50**：传球走廊拦截/点掉概率与 `dwell_base` 共同决定失误产量，当前拦截链偏强；
4. **回合数 ~259 > ~200**：回合时长偏短（avg 14.7s 且大量亚秒回合），进攻时间没有真实消耗——`dwell_base`、`action_duration_seconds` 与决策重选间隔共同决定。

**关键洞察**：修命中率会联动修构成（命中回归真实后三分效用自然下降），但**不能只修命中率**——效用结构对距离的梯度必须真实（中距离必须有存在的局势），否则 2P 出手仍不会回来。

### 6.2 校准顺序（严格按归因账本选题，protocol.md §3）

每步都走完整校准协议（基线快照 → JSON override 实验 → ≥8 seed 对比 → 归因 diff → 过门后进默认值）：

- **D3.1 命中模型优先**：标定 `shot_make_3pt`/`shot_make_2pt` 基线与距离衰减，目标 3P% ∈ [30,40]、2P% ∈ [48,58]（先验带）；收敛 `shot_pct_ceiling` 使其仅在极端局势生效；`spacing_bonus` 改为乘法小修正或封顶加性，消除线性叠加；
- **D3.2 出手构成跟随**：在命中模型修正后，用 `three_point_utility_multiplier` 与局面项（clock/比分/空位度）微调构成，目标 `SHOT_PROFILE_3PA_RATE` 与 `ZONE_MIX` 入带——**中距离回归的标志是 ZONE_MIX 中距占比 > 0 且入带**；
- **D3.3 失误率**：沿 D0 账本给出的失误结构（steal/tipped/dropped/violation 占比）选参数：拦截概率链（ResolveConfig）与 `dwell_base`；目标 `TURNOVER_RATE` ≤ 0.35 且失误构成比例合理（真实失误中传球失误为主）；
- **D3.4 节奏**：`PACE_POSSESSIONS` 入带；若回合时长仍偏短，检查进攻时钟实际消耗分布与决策重选间隔，而非单纯加 dwell；
- **每步输出**：`baseline_stats.json` vs `candidate_stats.json` + 归因账本 diff，进 PR。

### 6.3 机制层证据要求（防曲线拟合，与分布证据并行强制）

每个 D3 子步的 PR 除分布对比外，必须同时附：

1. **扰动测试不退化**：`cargo test -p nba-engine --test attribute_perturbation` 全绿——证明统计形态的变化来自能力通道而非新增常数/脚本；
2. **场景定性正确**：新增/维护的反事实场景测试（见 §1 P4 第三层）至少覆盖：快攻大空位敢出手、大比分领先末节压节奏、节末压哨不拒投——这些是全局分布拟合**伪造不了**的行为签名；
3. **常数守卫零新增**：`check_inline_constants.py` 棘轮不升——校准只改规则通道值，不得引入新内联常数；
4. **归因定向收缩**：目标准则缺陷率下降且**无其他准则缺陷率上升超过噪声阈**（摁下葫芦浮起瓢检测，§11 风险表）。
