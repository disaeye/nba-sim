# NBA-Sim · 迭代路线

> 文档类型：稳定的里程碑顺序和依赖图，不是当前完成度报告。
> 当前门状态见 `docs/dev/status.md`；当前未完成工作见 `docs/dev/current/plan.md`；验收语义见 `docs/protocol.md`。

## 0. 文档目的

本路线回答“先建立什么、后建立什么”。它不记录某个周期是否完成，也不复制代码实现和实验输出。

## 1. 里程碑

| 里程碑 | 核心交付 | 依赖 | 主要出口 |
| --- | --- | --- | --- |
| **M1 不变量内建** | 每步状态的 L1 物理/篮球底线、严重度和结构化工件 | 无 | Hard/Soft 语义、负面对照和调用方失败传播 |
| **M2 球态收敛** | 球权/最后触球单一事实源、状态转换表、派生视图 | M1 | 非法边拒绝，球权相关字段不重复承载真相 |
| **M3 确定性基线** | 固定输入重放、replay digest、黄金回归和 manifest | M1 | 同输入得到可比较的事件和状态摘要 |
| **M4 阶段化主循环** | 显式阶段序列、窄写权限、不可绕过的不变量阶段 | M2、M3 | 每阶段可单测，短路路径有定义 |
| **M5 执行重校验** | 意图与执行分离，实施时基于当前世界重新检查 | M2 | 降级/取消动作可追踪 |
| **M7 参数收编** | 行为参数进入规则/档案通道，审计阈值与运行阈值分离 | M3 | 校准可通过覆盖进行，守卫负面对照有效 |
| **M8 评判闭环** | 回合/阶段裁决、参考分布、固定分母、归因账本和证据工件 | M3、M7 | 评判不把证据缺失算成通过 |
| **M9 能力涌现** | 维度消费链、扰动响应、机制/反事实门 | M7、M8、attributes 规格 | 能力改变机会、执行或结果，断路测试有效 |
| **M10 多联赛** | `LeagueProfile`、程序语义和 profile 情景矩阵 | M7、M8 | 档案切换不产生联赛专用引擎分支 |

## 1.1 顺序原则

```text
M1 检测网 ─► M3 确定性 ─► M7 校准通道 ─► M8 评判闭环
                                      ├─► M2 ─► M4
                                      ├─► M5
                                      ├─► M9
                                      └─► M10
```

先建立检测、确定性和证据，再进行高风险状态重构与行为扩展。M9 和 M10 都依赖 M8，因为没有可信评判就无法区分机制改进与展示/统计变化。
