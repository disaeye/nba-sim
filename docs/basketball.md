# NBA-Sim · 比赛过程规格

> 定位：单场篮球如何从机会走到结果的规格。本文档定义动作生命周期、结果权、防守责任、接触与罚则程序。
> 上游：`docs/charter.md`。系统组织见 `docs/architecture.md`，输入见 `docs/attributes.md` 与 `docs/tactics.md`，观测见 `docs/quality.md`。
> 修订纪律：本文档只写比赛机制。实现范围、测试数字和执行顺序进入 `docs/dev/`。

## 0. 文档目的

本文档回答四件事：

1. 一次篮球行为从发起到结束经历哪些事实；
2. 命中、接球、突破、篮板和犯规在哪个事实出现时才能成立；
3. 防守责任如何从对位转到协防、换防和恢复；
4. 违例、罚则和账本如何从同一组事实重建。

球员能力、倾向和档案字段的分类学仍以 `docs/attributes.md` 为准。战术档案的 schema 仍以 `docs/tactics.md` 为准。本文档规定这些输入必须改变哪些比赛事实。

## 1. 过程原则

| # | 原则 | 含义 |
| --- | --- | --- |
| B1 | 结果属于过程 | 命中、接住、抢断、封盖、犯规和篮板只能在对应物理或规则事实出现时发布 |
| B2 | 意图不是命令 | 决策产出候选和意图；执行前按当前世界重校验，失败则取消、降级或改写 |
| B3 | 动作可中断 | 每个已进入比赛的动作都有开始、执行、完成、取消、失败五类事实中的适用子集 |
| B4 | 责任可交接 | 每次防守选择都有触发人、原责任人、接替人和恢复条件 |
| B5 | 规则是程序 | 违例和犯规发布种类、责任人、计时状态和罚则；账本只消费这些事实 |
| B6 | 联赛只换档案 | 同一套程序读取 `LeagueProfile`。NBA 与 FIBA 的差异写在档案字段，不写成分叉的比赛逻辑 |

随机性只允许出现在规则声明的边际判定上，并且绑定具名随机流。固定输入和种子下，事实顺序不变。

## 2. 动作生命周期

### 2.1 公共事实

一个进入比赛的动作至少发布：

- `ActionStarted`：动作种类、执行人、开始 tick、目标或对象；
- `ActionPhaseChanged`：准备、执行、随挥之间的阶段变化；
- `ActionCompleted`、`ActionCancelled` 或 `ActionFailed` 三者之一。

取消必须带原因：重校验失败、被更早的犯规或违例终止、动作窗口结束前控制权丧失。失败必须带失败事实，例如封盖、掉球、非法掩护或超时。完成不得提前包含尚未发生的结果。

动作窗口锁定运动学时，锁定本身是动作事实。窗口结束、取消或失败必须解除锁定。

### 2.2 有球动作

| 动作 | 开始时保留 | 结果事实 | 完成后的球态 |
| --- | --- | --- | --- |
| 跳投、后撤、转身、抛投 | 出手人、出手点、动作细分、可见防守、命中概率输入 | 离手、封盖、触筐、入筐或弹出 | 死球得分、触筐篮板或封盖松球 |
| 上篮、扣篮、反手上篮 | 终结人、接近路线、终结细分、接触对象 | 离手或触筐前封盖、得分、打铁、投篮犯规 | 同上，投篮犯规进入罚则 |
| 传球、击地、击板、手递手 | 传球人、目标人、冻结意图点、飞行参数 | 接住、掉球、点出、抢断、出界 | 持球、松球或死球 |
| 运球推进、变向、转身、胯下、背后 | 持球人、运球手、轴心脚、步数 | 继续持球、被拨出、走步、二次运球 | 持球或松球 |
| 背身进攻 | 背身人、防守人、低位位置、接触侧 | 挤开、投篮、传球、进攻犯规、五秒背筐 | 新动作或死球 |
| 罚球 | 罚球人、序号、是否末罚、罚则来源 | 出手、入筐、触筐、罚球违例 | 下一罚、篮板或发球 |

跳投细分 `JumperKind`、运球细分 `DribbleMoveKind`、篮下细分 `RimFinishKind` 和背身细分 `PostMoveKind` 只有在声明了窗口、可中断条件和可观测结果后才能进入候选。没有这些事实的细分保持为未接入类型，不产生比赛行为。

### 2.3 无球动作

下列动作各自是一次可完成或失败的动作，不只是目标点偏移：

| 动作 | 完成条件 | 失败或取消 |
| --- | --- | --- |
| 掩护建立 | 掩护人停稳、面向合法、与被掩护人间距合法并保持到接触窗口结束 | 移动掩护、距离不足、提前离位 |
| 顺下 | 掩护完成后沿篮筐方向进入终结或接球窗口 | 路线被封、掩护未建立、回合结束 |
| 外弹 | 掩护完成后到达档案声明的外线接球区 | 同上 |
| 滑出 | 接触形成前离开掩护点并进入接球窗口 | 没有提前离位事实则不是滑出 |
| 背切、空切 | 从弱侧或底线进入接球走廊并形成接球机会 | 路线被占、球已离手且无法到达 |
| 上提、闪切、定点转移 | 到达新的接球点并保持可传球窗口 | 目标区被占或窗口超时 |
| 卡位 | 在篮板落点前建立合法身体位置 | 失位、进攻犯规、球落在不可及范围 |
| 补篮 | 进攻篮板控制后在同一回合进入终结窗口 | 控制后改为传导或被犯规中断 |

无球动作可以由 Play 动词、战术槽位或球员倾向触发，触发后仍走本节的生命周期。多个无球动作可以并行，但同一球员同一 tick 只能有一个未完成动作。

## 3. 结果权

### 3.1 总规则

动作开始时可以保存当时可见的输入、概率和随机流标识。它不能保存命中、犯规、接住、封盖或篮板归属。结果事件的 `parent_event_id` 指向决定该结果的飞行、接触、封盖、触筐或规则事实。

同一输入在决定性事实不同时必须得到不同结果。例：同一出手参数遇到成功封盖时不能再发布入筐；封盖失败后仍由触筐事实决定命中或打铁。

### 3.2 投篮

1. 决策和释放前重校验只决定是否出手，以及出手时刻的防守距离、出手点和动作窗口；
2. 出手分区只由 `CourtGeometry::shot_zone` 决定：篮下小于 5 英尺、近筐 5 至 14 英尺、中投至少 14 英尺且位于三分线内、三分优先。分区输入是释放时刻出手点；
3. 球离手发布 `ShotRelease`。此时记录概率输入和分区，不记录命中布尔值；
4. 飞行期间，封盖窗口内的合法接触可以发布 `BlockedShot` 并把球变为松球；
5. 未被封盖的球到达篮筐后，触筐事实同时决定入筐、打铁、触板或篮筐干涉；
6. 投篮犯规来自出手动作期间的非法接触。接触成立时才发布犯规和罚则，不在离手前抽签预写；
7. 打铁后的反弹初速来自入射方向、接触点和恢复系数。落点是反弹飞行的结果。

封盖、打铁和篮板是三种后续：封盖进入松球争抢，打铁进入触筐反弹，进攻篮板不结束原回合。

### 3.3 传球

传球释放时冻结传球人意图点、目标人和飞行参数。接球人使用自己的可见信息和预估误差移动，不能读取传球人私有落点。

球到达目标窗口时只发生一种结果：

- 接球人在有效接球范围内并完成控制：`PassReceived`；
- 到达但未控制：`PassDropped`；
- 防守人触球但未控制：`PassTipped`；
- 防守人在飞行中完成控制：`PassIntercepted`；
- 球出界：`BallOutOfBounds`。

接球位置与意图点不同时发布 `PassLandingCorrected`。修正是事实，不是事后猜测。抢断必须发生在球的飞行走廊或合法接触窗口内。

### 3.4 突破与背身

突破开始只保存路线、目标和身体状态。接触、封堵、带球撞人和终结发生在对应窗口：

- 路线被合法防守阻断且未形成终结：突破失败；
- 进入终结窗口：转入投篮动作，由第 3.2 节决定入筐；
- 防守非法接触：犯规及罚则；
- 进攻人撞击已建立合法位置的防守人：进攻犯规；
- 球被拨出：松球，最后触球人是拨球防守人。

背身的挤开、勾手、后仰和上下步都是背身动作的后续分支，不单独预写得分。

### 3.5 篮板与松球

触筐反弹、封盖和未接住的传球都进入不受控球。控制权在球员实际完成控制时发布，发布前没有篮板归属。

前场篮板继续原进攻回合并按档案重置进攻时钟。后场篮板结束原回合并开始新回合。两人同时满足控制条件时进入争球程序，不按名单顺序分配。

补篮是进攻篮板控制后的新终结动作，保留与原出手的父链。它不是原出手结果的改写。

## 4. 防守责任

### 4.1 责任状态

每个防守人在任一 tick 有且只有一个主责任：

`对位`、`延误`、`挤过`、`绕过`、`换防后对位`、`协防`、`沉退`、`补位`、`回位`。

主责任之外可以有一个短暂辅助任务，但辅助任务必须声明结束条件。责任变化发布 `DefenseResponsibilityChanged`，包含触发事实、原责任人、新责任人和被接管的进攻人。

初始对位来自 `docs/tactics.md` 的对位纯函数。比赛中的换防和轮转只通过本节的责任事件修改当前责任，不改写原始对位档案。

### 4.2 挡拆覆盖

一次挡拆至少包含掩护接触事实、持球人利用事实和防守选择事实。防守档案可以给不同选择设权重，真正执行的选择必须是以下之一：

| 选择 | 触发 | 原对位人 | 掩护人防守者 | 失败 |
| --- | --- | --- | --- | --- |
| 挤过 | 接触前从掩护肩侧穿越 | 继续跟持球人 | 保持对掩护人 | 被挡死则转为绕过或换防 |
| 绕过 | 从掩护外侧追赶 | 继续跟持球人 | 短暂延误后回位 | 追防距离超过档案阈值则协防补入 |
| 延误 | 掩护人防守者上提接触持球人 | 从掩护后方接回持球人 | 延误后回原对位或换防 | 回位晚形成空位 |
| 换防 | 两人路径交叉且档案允许 | 接掩护人 | 接持球人 | 错位超过档案容忍度时弱侧补强点 |
| 沉退 | 掩护人防守者退向篮筐 | 继续跟持球人 | 保护篮下至威胁解除 | 外线空位由弱侧协防接管 |

每次失败都发布可观察的空位、错位或补位事实。中性防守档案必须回到换防和协防都不触发的基线。

### 4.3 协防、补位与回位

协防触发条件来自持球威胁、掩护、突破进入禁区和弱侧空位。协防人离开自己的对位人时，必须同时指定：

1. 谁临时接管被离开的进攻人；
2. 协防结束条件：持球人传出、突破停止、掩护解除或责任人回位；
3. 未完成接管时的空位事实。

低位协防、弱侧补位和 X-Out 关闭只是协防的目标不同，责任链相同。势能场可以提供空间度量，不能代替责任事件。

## 5. 接触、犯规与罚则

### 5.1 接触分类

物理层发布接触位置、速度、方向和参与者。语义层把它分类为掩护、合法身体接触、阻挡、带球撞人、推人、拉人、非法用手、投篮接触、松球接触或无吹罚。裁决层根据分类、动作阶段和 `LeagueProfile` 发布结果。

边际接触可以不吹罚，但 `NoCall` 也是事件。吹罚概率使用具名随机流，输入包含接触强度、动作合法性和相关能力。

### 5.2 犯规种类

| 种类 | 进入个人犯规 | 进入球队犯规 | 罚则 |
| --- | --- | --- | --- |
| 普通防守犯规 | 是 | 是 | 未入罚则时对方发球；入罚则后按档案罚球 |
| 投篮犯规 | 是 | 是 | 球进追加一次罚球；球不进按出手分值罚球 |
| 进攻犯规 | 是 | 否 | 对方发球，不增加球队犯规 |
| 松球犯规 | 是 | 是 | 未入罚则时对方发球；入罚则后按档案罚球 |
| 双方犯规 | 双方都计个人 | 不计球队 | 无罚球，按控制权恢复 |
| 技术犯规 | 按档案 | 按档案 | 一次罚球后按档案恢复球权 |
| 违体或恶意犯规 | 是 | 是 | 罚球加球权，达到档案次数后取消资格 |
| 转换路径犯规 | 是 | 是 | 仅档案启用时：两次罚球加球权 |

进攻犯规包括非法掩护、带球撞人和进攻人主动伸展造成的接触。转换路径犯规只在档案声明该种类时启用。

### 5.3 罚则重建

每一次犯规事件都带犯规人、被侵犯人、种类、是否投篮动作、出手分值、当前个人累计、当前节球队累计和罚则。账本按事件顺序重建：

1. 个人累计达到 `max_personal_fouls` 后，该球员退出在场名单；
2. 节球队累计达到 `bonus_team_foul_limit` 后，后续适用犯规进入罚则；
3. 罚球次数、是否保留球权和发球位置全部来自罚则事件；
4. 罚球结果只由对应 `FreeThrowAttempt` 记分；
5. 双方犯规和技术犯规不得用同一套默认两次罚球替代。

节末清零球队累计，不清零个人累计。加时是否单独计球队犯规由档案声明。

## 6. 违例与计时程序

### 6.1 计时

比赛时钟、进攻时钟、后场计时和各类违例计时只在规则规定的控制状态下推进。松球、投篮飞行、死球和暂停期间停止相应计时。

时间结束时已经离手的投篮继续到入筐、打铁或进攻人触球。防守人在信号后的触球按干扰条款处理，不把投篮提前判死。

### 6.2 通用违例

| 违例 | 成立条件 | 罚则 |
| --- | --- | --- |
| 出界 | 最后触球后球接触界外 | 对方就近发球 |
| 走步 | 超过档案允许的停步、轴心脚或运球开始限制 | 对方发球 |
| 二次运球 | 合法运球结束后再次运球 | 对方发球 |
| 回场 | 前场控制后本队首先在后场触球 | 对方发球 |
| 后场超时 | 连续后场控制超过 `backcourt_seconds` | 对方发球 |
| 进攻时钟 | 控制超过时限且球未在时限前离手并随后触筐或入筐 | 对方发球 |
| 发球违例 | 超时、踩线、球未触场上球员或发球人场内触球 | 对方在原发球点发球 |
| 攻方三秒 | 前场控制时进攻人在限制区连续停留超过时限 | 对方发球 |
| 贴身防守五秒 | 档案启用且防守人在声明距离内连续防守达到时限 | 对方发球 |
| 背筐五秒 | 档案启用且前场低位背筐运球超过时限 | 对方发球 |
| 进攻干扰 | 球在限制圆柱或已触筐后被进攻人非法触碰 | 得分取消，对方发球 |
| 防守干扰 | 球下降、已触板或档案规定的触筐阶段被防守人非法触碰 | 判给对应分值 |

三秒、五秒和干扰的空间边界、暂停条件来自 `LeagueProfile`。档案未启用的条款不产生违例。

### 6.3 联赛差异

首批档案只覆盖 NBA 与 FIBA。程序相同，字段不同：

| 程序 | NBA 档案 | FIBA 档案 |
| --- | --- | --- |
| 节数与节时长 | 4 节，每节 12 分钟 | 4 节，每节 10 分钟 |
| 加时 | 5 分钟，开局跳球 | 5 分钟，开局使用交替拥有 |
| 进攻时钟 | 新控制 24 秒；触筐后进攻队获得球 14 秒 | 新控制 24 秒；触筐后原进攻队获得球 14 秒 |
| 防守犯规后的进攻时钟 | 前场发球取剩余时间和 14 秒的较大值 | 前场发球按档案的 14 秒或继续计时规则 |
| 后场 | 8 秒 | 8 秒 |
| 个人犯规离场 | 6 次 | 5 次 |
| 球队罚则 | 每节第 5 次球队犯规起，加时有独立限额 | 每节第 5 次球队犯规起；加时累计计入第 4 节 |
| 非投篮普通犯规 | 罚则中一次罚球加一次罚则罚球 | 罚则中两次罚球 |
| 三分线 | 弧顶与底角不同 | 等半径，底角无特例 |
| 争球 | 跳球 | 交替拥有箭头 |
| 防守三秒 | 启用，技术犯规并保留进攻球权 | 不启用 |
| 转换路径犯规 | 启用 | 不启用 |
| 贴身五秒 | 不启用 | 启用 |
| 干扰 | 触筐后仍限制触球 | 球触筐后结束干扰限制 |
| 暂停 | 常规时间 7 次，受单节和末段限制；加时 2 次 | 上半场 2 次，下半场 3 次且末两分钟最多 2 次；加时 1 次 |

`LeagueProfile` 因此必须带程序字段，而不是只有时长和距离。字段包括罚则形式、暂停配额、交替拥有、防守三秒、转换路径犯规、贴身五秒、干扰触筐规则和进攻时钟重置表。

## 7. 回合与账本

一个进攻回合从获得控制开始，到得分、防守篮板、失误或节末结束。进攻篮板、补篮和前场继续控制属于同一回合。罚球是否属于新回合由产生罚球的终结事实决定，并在回合摘要中保留来源。

每次终结发布 `PossessionEndCause` 和父事件。得分、球权、时间、犯规、罚球和失误六类账本都必须能只从事件重建：

- 得分只来自入筐和成功罚球；
- 球权变化只来自回合终结、跳球或交替拥有；
- 时间片之和与比赛时钟一致；
- 个人犯规、球队犯规、离场、罚则和罚球逐条对应；
- 每次失误有责任人和违例或失去控制事实。

无法从事件确定的终结是完整性失败，不使用默认原因补齐。

## 8. 与其他规格的边界

- `docs/architecture.md` 规定这些事实在哪个阶段产生和哪一层可以写入；
- `docs/attributes.md` 规定能力与倾向如何改变动作机会和执行质量；
- `docs/tactics.md` 规定档案如何改变候选、匹配和责任选择；
- `docs/quality.md` 规定动作、责任、犯规和结果事实如何被检查；
- `docs/protocol.md` 规定改动这些机制时需要的证据；
- `docs/decisions.md` 只保留跨规格取舍，不复制本节的程序正文。
