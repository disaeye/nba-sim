# 物理与接触模型盲区登记

版本：v2

## 当前盲区

### 1. 接触后的比赛级分布

ADR-017 第三步已经覆盖传球、持球、突破持球、自由球和篮板飞行的接触几何与时间计算。以下指标仍需要独立比赛数据校准：

- 带球丢球、传球失误和拨球失误的构成；
- 抢断率、拨球率和传球成功率；
- 防守压力持续时间与失误结果之间的关系；
- 不同球速、接触距离和接触高度下的结果分布。

当前 `rules_complete_wiring` 只证明规则字段进入模拟指纹，不能替代这些分布门。

### 2. 篮板归属与二次进攻

触筐、篮板、篮板飞行中的球员身体碰撞已经进入物理路径。前场篮板率、后场篮板率、篮板争抢距离和补篮机会仍需要独立数据校准。物理模型当前只对单次碰撞和首次落地提供证据。

### 3. 复杂连续接触

当前模型记录每名防守者在一次传球或自由球飞行中的连续接触区间。多人同时接触、身体碰撞后再次手部接触、连续拨球以及接触顺序对结果的影响仍未由比赛级数据验证。

### 4. 出手结果与碰撞结果的联合分布

投篮命中或不中仍在出手阶段裁定，篮板和球员碰撞在飞行阶段处理。命中率、出手弧线、封盖、篮板距离和二次进攻之间的联合分布仍缺少独立门。

### 5. 个体与序列行为

球员级护球能力、外线防守、敏捷、风险容忍度，以及失误后下一回合节奏的长期影响仍缺少足够证据。当前测试覆盖规则扰动和短窗口行为变化，不能证明完整比赛序列已经符合真实比赛。

## 登记纪律

每次确认新的数据缺口时增加条目并保留版本号。数据证据不足时保留盲区，不宣称模型已经覆盖。
