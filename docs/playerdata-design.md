# 一、球员数据体系分层设计

## 1.0 术语约定（全文锁定）

| 术语 | 专指 | 数量 | 可见性 |
|------|------|------|--------|
| **体测** | 物理层 | 8 项 | 公开（耐久隐藏） |
| **能力** | 能力层（Ability） | 24 项 | 隐藏 |
| **倾向** | 倾向层（Tendency） | 9 项 | 隐藏 |
| **判断** | 判断层（Awareness） | 4 项 | 隐藏 |
| **属性** | 展示层 | 7 项 | 可见（档位制） |
| **数据** | 上述五类的统称 | — | — |

**铁律**：全文中"属性"一词仅指展示层 7 项；提到能力/倾向/判断/体测时用专名，不得用"属性"代称。"数据"作 umbrella 用。

## 1.1 分层结构

```
第0层 物理层 = 体测（公开，不可训练）       身高/体重/臂展/弹跳/速度/横移/年龄/耐久(隐藏)
第1层 模拟层（隐藏，决策树真实读取）        能力 24项 / 倾向 9项 / 判断 4项
第2层 展示层 = 属性（可见，档位制）         投射/终结/组织/外防/内防/篮板/运动 共7项
关联机制 球探观测（属性=模拟层与体测的观测估计值，含误差）
```

数据流向单向：物理层 → 模拟层 → 比赛事件流 → 观测模型 → 展示层。玩家一切操作只作用于下层，展示层只读。

## 1.6 展示层 = 属性（完整枚举，7 项）

**聚合公式**（真值，非观测值）：
```
D_true = 0.7 × Σ(wᵢ·aᵢ) + 0.3 × min(aᵢ)
```
0.7/0.3 为短板效应权重 ⌛。各属性的完整权重表：

| 属性 | 权重构成（Σw=1） |
|---------|----------------|
| 投射 | CS3 .35 / OD3 .25 / CSM .20 / PUM .10 / FT .10 |
| 终结 | FINC .25 / DUNK .25 / FINS .20 / FINW .15 / FLT .15 |
| 组织 | PASS .30 / PASM .25 / OFFR .20 / POCK .15 / HND .10 |
| 外线防守 | POBD .40 / NAVS .25 / SWCH .20 / STL .15 |
| 内线防守 | RIM .45 / DEFR .30 / BOX .25 |
| 篮板 | ORB .35 / BOX .35 / DEFR .15 / VJ_n .15 |
| 运动能力 | SPD .35 / LAT .30 / VJ_n .35 |

**档位映射**：S=90+，A=85~89，A-=82~84，B+=78~81，B=74~77，B-=70~73，C+=66~69，C=62~65，D=55~61，F<55。

**观测模型**：`D_shown = D_true + ε`，ε~N(0,σ²)，`σ = 12 × k_scout × √(200/n)` ⌛（属性真值 D_true 由 1.6 聚合得到）
- k_scout：L1=1.5 / L2=1.2 / L3=1.0 / L4=0.8 / L5=0.6
- n = 被观察回合数，封顶 2000（σ 永不归零）；数据大幅变动后旧样本按半衰期 500 回合衰减 ⌛
- 呈现规则：σ ≥8 时档位显示为范围（如"B ~ A-"），σ <8 显示单档（详见球探报告呈现，本文 1.7）

## 1.7 球探报告呈现（完整规则）

报告五区块：体测区（精确值）/ 能力档位区（档位+5 格置信条）/ 风格描述区（3~5 条文案）/ 角色适配区 / 样本区（"已观察 N 回合"）。

**风格文案生成表**（Tendency 观测值 → 文案）：

| Tendency | ≥70 | 40~70 | ≤40 |
|----------|-----|-------|-----|
| T3 | "痴迷外线出手" | — | "几乎不投三分" |
| TDRIVE | "喜欢持球冲击" | — | "很少突破" |
| TPOST | "热衷背身要位" | — | "不去低位" |
| PASS1ST | "乐于分享球" | — | "球到他手里就停了" |
| TAKEOVER | "关键时刻要球" | — | "关键时刻隐身" |
| GAMBLE | "防守爱赌博" | — | "防守稳健不失位" |

**稀有组合文案**：高难度倾向高+能力高 → "投篮选择糟糕，但就是能进"；TAKEOVER 高+Ability 低 → "自信的普通球员"；TPOST 高+POST 低 → "活在上个时代"。

**解锁节奏**：L1 体测+宽范围档位；L3 +风格描述+角色适配；L5 σ 减半、单档呈现。

## 1.8 观测模型扩展（Tendency / Awareness / Fit）

1.6 的 σ 公式不仅适用于展示层，**同样适用于 Tendency 与 Awareness**——这三类隐藏量对玩家都是"观测值 + 误差"。

```
Tendency_obs = Tendency_true + ε_t,   ε_t ~ N(0, σ_t²),   σ_t = 15 × k_scout × √(200/n) ⌛
Awareness_obs = Awareness_true + ε_a, ε_a ~ N(0, σ_a²),   σ_a = 10 × k_scout × √(200/n) ⌛
```
- σ_t 基准 15 > σ_a 基准 10 > 展示层 12 ⌛——**倾向比能力更难观测**（一个人"愿不愿意投"比"投得准不准"更隐蔽），球探报告 L3 才解锁风格描述即对应此
- 球探报告 1.7 的风格文案读取的是 Tendency_obs，非真值
- **观测 Fit**：玩家在角色适配区看到的 Fit 用观测值计算（D_shown + Tendency_obs + Awareness_obs 代入 5.1 公式），带与展示层同源的误差；真值 Fit 仅模拟器内部使用

# 二、角色体系完整设计

## 2.1 结构

- **双槽位**：每名球员 = 1 个进攻角色 + 1 个防守角色，阵容内各占一个槽位
- **池选制**：进攻角色池 10 种、防守角色池 7 种，一套阵容从池中各选 5 个（允许重复，重复触发球权/化学反应约束）——阵容组合空间 = C(10+4,5) × C(7+4,5) 级别，不存在"所有阵容一样"的问题
- **角色绑定阵容，不绑定球员**；球员侧持 Fit 向量（第五章）
- 角色不提供数值加成，只改写决策树分支权重与入口优先级

**球权分配规则（两段式）**：
1. 先按需求值算每人的**名义份额** = 需求值 / Σ需求值
2. 若名义份额导致"重复高需求角色"或化学反应相克（2.4），触发**冲突压缩**：按 Fit 升序，Fit 低者的实际份额向需求值偏离方向回调，直至相克项消化
3. 最终实际份额归一化到 92%（余量 8% 为随机事件与空缺惩罚缓冲 ⌛）
4. 需求值 ≠ 固定份额——全低需求阵容归一化后球权自动分散，这就是"全民皆兵"阵容的来源

## 2.4 化学反应（完整枚举）

机制：化学反应 = 决策树分支概率修正（±10% ⌛），非数值加成。

**相生（8 组）**：

| 组合 | 修正 |
|------|------|
| 持球核心 × 无球射手 | 核心突破/单打分支的协防到位概率 −10% |
| 持球核心 × 空切终结 | 喂饼分支激活（核心 PASS1ST≥40 时切入目标权重 +10%） |
| 副攻手 × 持球核心 | 核心被包夹时副攻手接应权重 +10% |
| 组织枢纽 × 空切终结 | 传切激活：切入目标权重 +10% |
| 组织枢纽 × 跑动射手 | 发牌激活：移动接球分支频率 +10% |
| 单打得分手 × 无球射手 | 拉开单打：ISO 分支空间判定 +10% |
| 背身轴心 × 跑动射手 | 内外呼应：包夹轴心时射手空位概率 +10% |
| 盯人箭头 × 护筐锚 | 箭头压迫失败后的失位惩罚 −10% |

**相克（7 组）**：

| 组合 | 修正 |
|------|------|
| 持球核心 × 持球核心 | 球权需求超限，按 Fit 排序衰减（§2.5） |
| 持球核心 × 单打得分手 | 同上：双持球冲突 |
| 持球核心 × 组织枢纽 | 发起权冲突：两人发起权重各 −10% |

**重复角色通用规则**：同一角色重复 ≥2 人，除上表已列的持球核心/无球射手外，其余角色按类型查表——终结类（空切/内线/背身）重复 → 油漆区拥堵 −10%；发起类（核心/ISO/枢纽）重复 → 球权冲突按 2.5 压缩；防守赌博类（纠缠者/扫荡）重复 → 防线真空 +10% 失位惩罚。

## 2.5 球权预算与空缺规则

- 球权按 2.2 两段式分配；冲突压缩由化学反应相克项驱动，不再设独立的">100 阈值"——是否冲突看角色组合（2.4）而非需求值总和
- **角色空缺**：某进攻职能无人担任 → 该职能按 Fit 临时顶班，效率 ×0.85 ⌛
- **强扭的瓜**：Fit <50 的球员硬塞角色 → 执行效率 ×0.80 ⌛ + 触发"体系不适"事件（第四章 4.4）

# 三、外界因素对数据的影响

## 3.1 训练系统

**训练点**：每赛季每球员获得 100 点 ⌛，玩家自由分配到具体 Ability（物理层、Tendency 不可训练；Awareness 训练效率 ×0.3）。

**成长公式**：
```
Δa = 点数 × 0.14 × 年龄效率 × (1 − a/POT)
```
- 系数 0.14 ⌛（v1.3 从 0.02 上调；目标：20 岁 a=55/POT=85 的 prospect 训练满投约 +5/年，5 年接近天花板）
- **POT（潜力天花板，隐藏）**：每个 Ability 独立设定，生成时确定，范围 40~99；a 越接近 POT 成长越慢，到达即停
- **年龄效率**：18~21=1.0 / 22~25=0.8 / 26~28=0.5 / 29~32=0.25 / 33+=0.1 ⌛
- **自然成长**（无训练投入时，成长期内自动）：等效 30 训练点/年，与玩家投入的训练点叠加

**可训练性完整表**：

| 投篮组 | CS3/OD3/CSM/PUM/FLT/FT | 全额 |
| 技术组 | HND/PASS/PASM/POCK/SCRN/POST/FINW | 全额 |
| 终结组 | FINS/FINC/DUNK | 全额（受身体衰减拖累，见 3.2） |
| 防守组 | POBD/NAVS/SWCH/RIM/STL/BOX/ORB | 全额 |
| 判断组 | OFFR/DEFR/SPC/PLY | ×0.3（主要靠比赛经验，第四章） |
| 体测 | 全部 | 不可训练（仅 WT 可 ±5kg 微调） |
| 倾向 | 全部 | 不可直接训练（仅角色浸润，第四章） |

# 五、球员数据与角色的关联关系

## 5.1 Fit 公式（完整定义）

```
Fit(球员, 角色) = f × g × 100
f = 0.7 × Σ(wᵢ·aᵢ) + 0.3 × min(aᵢ)        ← 能力短板聚合（沿用 1.6 结构）
g = Π gᵢ                                    ← 倾向门槛连乘
gᵢ = 1                        若满足门槛
gᵢ = 0.5 + 0.5 × (实际值/门槛)  若不满足（≥ 型门槛，平滑惩罚）
gᵢ = 0.5 + 0.5 × (门槛/实际值)  若不满足（≤ 型门槛）
```

**Fit 分档**：≥80 天然契合 / 65~79 可胜任 / 50~64 勉强 / <50 错位（触发 4.4）。

> 玩家可见的是**观测 Fit**（用 1.8 的观测值代入），带误差；真值 Fit 仅模拟器内部使用。

# 六、战术体系完整设计

- **调用频率**：每 4~6 回合调用 1 次战术回合 ⌛，其余回合自由进攻（默认分支权重）

- **装备机制**：教练战术包容量限制同时装备的战术数（6.5）

## 6.5 战术执行（PLY 判断挂载）

```
P(剧本跑到位) = 0.70 + 0.004 × (全队PLY均值 − 60) + 熟练度修正
P(战术生效)  = P(剧本跑到位) × (1 − 0.3 × 偏离惩罚 × (1.3 − 0.3×Fit/100))
```
- 第一项：个体 PLY + 熟练度决定"跑不跑得出来"；第二项：角色 Fit 决定"跑出来后执不执行得动"——两者**乘法叠加**
- **熟练度**：每个战术独立经验条，每使用 1 场 +2%，上限 +25% ⌛
- **偏离** → 战术退化：跑位中断，回到 N2/N3 默认自由进攻分支
- 基准 0.70 ⌛（v1.3 从 0.55 上调，保证默认联盟战术能跑起来）；年轻球员多的球队 PLY 均值低，打不了复杂战术——与现实一致，且给老将/体系球员创造价值

| L5 | 8 | ×1.10 | 不限更换 |

## 6.7 对手识别与反制

- **识别**：对方全队 DEFR 均值 ≥65 且交手 ≥3 场 ⌛ → 识别该战术，其权重修正效果 ×0.6
- **连用衰减**：同一战术连续使用 ≥5 场，效果 ×0.8 ⌛（不依赖对手，模拟"被录像研究"）
- 复用球探样本机制：对手对你战术的"识别度"也是一种随样本收敛的观测
- 设计意图：战术包必须轮换，一招鲜吃半个赛季——教练运营成为长线玩法

## 6.8 与角色/数据体系的边界

- **角色是槽位（谁干什么），战术是剧本（怎么配合）**；战术消耗同一份球权预算，战术回合内角色权重被战术修正覆盖
- "战术适不适合阵容"由数据门槛自然回答，不引入额外匹配度数值
- 战术对球员成长的影响：战术回合计入比赛经验（4.1）；长期在 Motion 体系中打球 → 浸润效果视为"组织枢纽"类（PASS1ST 方向）⌛

# 七、球员生成器

## 7.1 生成流程（五步，顺序固定）

```
选原型 → 物理生成 → 能力采样 → POT 生成 → 倾向采样（含校验）
```

## 7.3 POT（潜力天花板）生成

```
POT(能力a) = clip( 生成值(a) + N(μ_age, σ_age), max(生成值+2, 40), 99 )
```
| 年龄段 | μ_age | σ_age |
|--------|-------|-------|
| 18~20 | 18 | 8 |
| 21~23 | 12 | 6 |
| 24~26 | 6 | 4 |
| 27+ | 2 | 2 |

规则：POT 逐能力独立；原型关键能力的 POT 额外 +5 ⌛（天才在其天赋方向上天花板更高）。

## 7.4 物理生成

- H：按原型分组采样——后卫类 183~198，侧翼类 195~208，内线类 205~225（均匀 + N(0,2)）
- WS/H：N(1.05, 0.03)，clip [0.98, 1.12]
- WT：由 H 推基准（H−100 ± 8），内线 +10
- VJ/SPD/LAT：原型相关（尖兵/大核 LAT≥70），N（原型均值, 8)
- DUR：N(60, 15)，clip [20,99]，**隐藏**；与原型无关（耐久不可观测）
- **PLY（战术执行）分布**：按原型——组织后卫/组织枢纽 均值 70，持球大核/单打得分手 65，3D 侧翼/全能工具人 60，其余 55；均加 N(0,8) 扰动。老将按 4.1 经验成长额外提升

## 7.5 倾向采样与校验

按原型倾向特征列采样 N（特征值, 10)，clip [5,95]，然后执行 1.4 节校验：出手四倾向归一化；TAKEOVER≥70 且 PASS1ST≥70 → PASS1ST 压 69。

## 7.6 选秀池与联盟生态

- 联盟规模假设：30 队 × 12 人 = 360 球员 ⌛
- 每年选秀池 60 人（两轮），年龄 18~22，原型占比按 7.2 表
- 生态约束：每届选秀池保证原型 1（持球大核）≥1 人、原型 10（空间型内线）≥2 人 ⌛——保证市场供应底线，稀缺性由质量分布制造而非数量归零
- 自由球员池 = 落选新秀 + 被裁球员；其展示层仍走观测模型，但因历史样本充足 σ 已趋近下限（接近真值，非显示真值）——"已知货"由样本量自然解释，不开特例

# 八、体力系统

## 8.1 体力值定义

```
STM（0~100），比赛开始 = STM_max
STM_max = max(50, 70 + 0.3×DUR − max(0, AGE−30)×2)
```
下限 50 ⌛：保证老弱球员开局不至于直接落入惩罚区。

## 8.2 消耗（每分钟在场）

| 角色/情境 | 消耗 ⌛ |
|----------|--------|
| 持球核心 / 单打得分手 / 组织枢纽 | 1.6 |
| 副攻手 / 背身轴心 / 纠缠者 / 盯人箭头 | 1.3 |
| 跑动射手 / 空切终结 / 转换箭头 / 协防扫荡 | 1.1 |
| 无球射手 / 内线终结 / 护筐锚 / 顶防工兵 / 纪律轮转者 / 换防摇摆 | 0.9 |
| 转换进攻回合 | ×1.2 |
| 全场紧逼战术回合 | ×1.5 |

## 8.3 恢复

- 下场休息：+2.0/分钟 ⌛；节间 +15；中场 +30
- 赛后恢复至 100 − 疲劳积累值（8.5）

## 8.4 体力对表现的影响（分段函数）

| STM 区间 | 效果 |
|---------|------|
| 60~100 | 无修正 |
| 40~59 | 执行效率 ×(0.85 + 0.15×STM/60) |
| 25~39 | 同上，且 OFFR/DEFR −5（疲劳降智） |
| <25 | 伤病概率 ×1.5；教练收到强制换人提示 |

## 8.5 疲劳积累（跨场）

```
疲劳积累 F = Σ(该场消耗 − 恢复盈余)，F ≥ 0
背靠背第二场：赛后恢复 ×0.7 ⌛
F > 20 → 伤病负荷系数 1.3（喂给 3.3 节伤病公式）
F 每场自然衰减 −8 ⌛
```

## 8.6 轮换规则（AI 与玩家提示）

- 默认轮换：STM <35 自动请求换人（玩家可覆盖）
- 场均 >36 分钟持续 10 场 → F 累积加速 ×1.3 ⌛（死艹主力的代价）

# 九、士气系统

## 9.1 定义

```
MOR（0~100），基准 60，无输入时每周向基准回归 10% ⌛
结算节奏：9.2 事件即时结算；每周休赛日做一次向基准回归（比赛日不回归）
```

## 9.2 输入事件（完整枚举）

| 事件 | ΔMOR ⌛ |
|------|---------|
| 赢球 / 连败每场 | +1 / −1 |
| 高光场次（效率队内前二） | +3 |
| 低谷场次（命中率 <30% 且出手 ≥10） | −2 |
| 首发 → 替补降级 | −8 |
| 替补 → 首发 | +5 |
| 连续 DNP 每场 | −2 |
| 关键时刻被按在板凳（最后 5 分钟不在场，当 TAKEOVER≥60） | −3 |
| 体系不适事件（4.4 触发） | −5 |
| 合同年开局 | +5（动力） |
| 被摆上货架（交易流言） | −6 |
| 夺冠 / 季后赛出局 | +15 / −5 |

## 9.3 输出（表现反馈，完整枚举）

| MOR 区间 | 效果 |
|---------|------|
| 75~100 | 执行效率 ×1.03；训练效率 ×1.1 |
| 45~74 | 无修正 |
| 25~44 | 执行效率 ×0.97；训练效率 ×0.9 |
| 10~24 | 执行效率 ×0.95；倾向侵蚀：TAKEOVER −2/月 |
| 0~9 | 触发"公开要求交易"事件；拒绝续约 |

## 9.4 与其他系统的接口

- 输入侧：出场时间、角色错配（4.4）、战绩
- 输出侧：场上表现（乘区修正，不碰真值）、训练（3.1）、交易 AI（5~7 缺口中的外围系统消费 MOR）
- **设计边界**：士气只影响表现波动和成长效率，**永不直接修改能力/倾向/判断真值**——真值变动只能来自第三、四章的机制

## 10.1 每条事件的必需字段（球员侧视角）

| 字段 | 消费方 |

| 查询 | 公式来源 |
